    • “小猫补光灯”：App Store 付费榜第一的产品故事

    2026-11-11 说书匠 书籍 0 Comments

    选择做什么、不做什么，永远是你自己的判断。

    讲了这么多工具的使用方法和技巧，你最关心的肯定是：怎样落地？

    本文就来介绍，作者是怎样不用亲自写代码，做出一款付费榜第一的产品的故事。

    （以下为作者第一人称）

    缘起

    2024年11月的一个下午，我在录制Cursor教程视频。女朋友坐在旁边帮我检查画面时，突然说了一句：“与其做屏幕手电筒，不如做补光卡片呢。”

    “补光卡片”是什么？我之前从没听过这个词，但我没有忽略这句话，而是打开小红书搜了一下。

    搜索结果让我愣了几秒。好几篇与“补光卡片”相关的笔记都获得了十几万赞。有人用纯色图片当补光板自拍，有人分享不同颜色的补光效果对比，有人在找“能调颜色和亮度的补光App”，但一直找不到好用的。

    我立刻意识到：这是一个真实的高频需求。需求已经被验证了，只是没人做成产品。

    5分钟后，我打开Cursor（当时还没用Claude Code），用自然语言描述了我想要的功能。1小时后，“小猫补光灯”就在App Store上架了。

    判断

    开发之前，首先要判断需求是否存在，然后是做成什么样。我做了三件事。

    第一，非程序员的建议。

    女朋友不懂代码，但她懂用户需求。“补光卡片”是她从小红书上看到的，真实用户的真实表达。如果我只跟程序员朋友讨论，应该不会想到这个方向。

    第二，3分钟验证需求。

    我没有凭直觉认为“这应该有人需要”，而是打开小红书搜了一下。获得十几万个赞的笔记就是最好的市场调研报告。

    第三，最小可行产品。

    第一版产品只聚焦核心功能：全屏显示一个纯色，支持调颜色和亮度。它没有滤镜、定时器、社交分享和会员系统，只是一个能调色的全屏灯。

    核心要领：不要考虑技术上能不能实现，先思考谁会用、在什么场景下用、市面上有没有替代品。如果很多人在讨论相关需求，但没有好产品能够满足，那就值得做。

    第一版能用，但远没到“好用”的程度。用户反馈会告诉你还需要做什么。

    App Store上架

    写代码只占整个开发过程的30%，剩下的70%是与上架相关的工作：注册开发者账号、进行证书配置、了解隐私政策、等待App审核。

    开发者账号

    要想在App Store中发布应用，需加入Apple Developer Program（年费约688元）。必须用真实身份注册，审核通常需要1～2天。

    证书和签名

    这是iOS开发中最“反直觉”的部分。你需要创建证书、配置描述文件、在Xcode中设置签名。

    App审核

    App Store的审核比Chrome Web Store严格得多。常见的拒审原因包括：

    • 缺少隐私政策页面（即使你的App不收集任何数据，也必须提供）

    • 截图和实际功能不符

    • 使用了私有API

    • 功能太简单（可能被判定为“可以用网页实现的功能，没有必要做成App”）

    “小猫补光灯”第一次提交就顺利通过审核，因为它的功能明确、界面简洁，没有灰色地带。审核大概用了24小时。

    爆火：运气还是必然？

    App上架后的第一周，我在小红书发了一篇笔记，内容很简单：展示了补光前后的对比效果。

    3天内，阅读量达118万，获得7.3万个赞。“小猫补光灯”App的下载量突破3万次。“Pro版本”（加了摄像头功能，售价6元）冲上了App Store付费榜第一名，并保持了一个多月。

    后来有媒体问我是怎么做到的。说实话，我自己也有点儿意外，但复盘之后，总结出以下几个关键点。

    需求强烈且明确。自拍补光是一个高频、刚需的使用场景。它不是“有了更好”，而是“没有不行”。

    产品足够简单。打开App就是一个全屏色卡，不需要注册，也没有学习成本。这种“打开就能用”的产品最容易传播。

    争议带来流量。很多程序员在评论区质疑：“这种App也能卖钱？”“1小时做出来的东西也配收费？”这些争议反而带来更多关注，让更多人知道这款App。

    快速迭代建立口碑。App爆火的那几天，我连夜改了3个版本：修复用户反馈的问题、加入呼声最高的功能。

    务实的期望管理。绝大多数“手搓”产品会无声消亡。“小猫补光灯”的成功包含运气成分：选对了赛道、赶上了小红书的推荐、产品形态恰好适合短视频传播。这些因素不是每次都能复制的。

    做产品的正确心态是：做好每一个环节，但不预设结果。

    真正重要的

    在这个故事里，技术是最不重要的部分。

    代码，Claude Code能写；上架流程，网上查得到；推广方法，各平台都有教程。

    真正决定成败的是3个非技术因素。

    • 能不能发现需求

    保持对日常生活的观察力，比任何编程技能更重要。

    • 能不能克制

    专注于产品的核心功能，不盲目添加社交、会员和广告等不必要的功能。极致的简单就是极致的竞争力。

    • 能不能坚持迭代

    爆火是偶然，持续提供价值是选择。在“小猫补光灯”之后，我又做了好几个版本，每个版本都在解决用户真实反馈的问题，这才是产品成功的关键。

    AI编程工具让“写代码”不再是瓶颈。这意味着竞争的维度从“谁能把代码写出来”变成了“谁能发现值得解决的问题”。

    Claude Code给了你实现任何想法的能力，但选择做什么、不做什么，永远是你自己的判断。
