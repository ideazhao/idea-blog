    • Claude Code 编程实战：外行人第一次可以独挑大梁

    2026-10-24 说书匠 书籍 0 Comments

    技术壁垒已不存在，你只需要有想法。

    过去，你想做互联网创业，要懂产品、懂设计、懂开发，是漫长的学习，繁琐的沟通，反复迭代，极大的人力和时间成本，稍有某个环节走不通，就进行不下去。

    但是现在，在AI的辅助下，这件事可以简单到什么程度？你只需要会打字。

    因为AI的大脑里装着所有你已经掌握和没有掌握的东西，还会自己分析、整理、解决问题。

    本系列介绍的这款工具，就是诸多工具中较为突出的一个。

    安装与用法

    作者第一次安装Claude Code的时候，只在终端输入了一行命令，30秒后就自动安装完成。接着，在对话框中输入claude并按Enter键，屏幕上立即出现闪烁的光标。输入“你好”，它立刻进行了回复。整个过程不到1分钟。

    至于你用什么方式安装，取决于你的系统，跟随官方指引即可。

    用法则分为：终端CLI、桌面端、网页、扩展/插件，跟个人习惯有关，随意选用，如果你想沉浸式不分心地工作，桌面端是比较合适的。

    第一条指令

    发指令之前，只需做好一项准备：让AI在哪里做事。也很简单，将你的项目目录设为工作目录即可（选择一个文件夹），便于Claude Code针对项目做文件的增、删、改等操作。

    随后敲一个“claude”，就会出现交互界面（如果已经登录了Anthropic账号）。

    第一条指令的作用是试一下你对它的沟通是否有效，你可以随意，但为了上下文统一，我们就写：

    你会看到Claude Code开始在你的目录中创建一个HTML文件，写入完整的代码。过程仅需10～30秒。

    然后可以在浏览器中查看效果，如果能看到一个带样式的“Hello, Claude Code!”页面，恭喜你，一切正常。

    这看起来非常简单，但意义不容忽视：一句自然语言，就让AI完成了“理解需求→创建文件→编写代码”的全过程。后面的所有进阶操作都建立在此基础之上。

    从现在开始，转变思维，你是产品经理，Claude Code是工程师。你要做的是说清楚要什么，告诉AI该怎么做。

    看它干活

    确认方案后，Claude Code开始执行。你会在终端看到一系列操作。

    写完代码后，Claude Code通常会试着运行一次看看有没有报错。如果报错，它会自己读错误信息、找问题、修代码、再运行，形成一个自动修复循环。

    整个过程需要2～5分钟。

    在执行过程中，Claude Code可能会多次请求权限。初期，建议你每次都看一下它要执行的命令，熟悉后可以用/permissions预授权常见命令（后面会细讲），或者直接启用Auto模式。

    新手建议

    1、看不懂代码？直接问。

    2、运行出问题？描述现象比定位代码行更有效，除非你知道问题出在哪儿。

    3、执行跑偏了？偏得不远，直接纠正。偏得太远，直接中断。

    4、该管到什么程度？基本原则：信任但验证。

    让Claude Code去做，但检查每一步的结果。

    方案阶段：仔细看，确保方向对。

    编码阶段：大致看一下文件结构。

    执行阶段：检查输出是否符合预期。

    改进阶段：多测试边界情况，如空数据、网络超时、格式异常。
